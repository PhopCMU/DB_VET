# Beautiful Web Design with Tailwind CSS

## เป้าหมาย

ออกแบบหน้าเว็บที่ดูตั้งใจออกแบบ ไม่ใช่เพียงนำคอมโพเนนต์สำเร็จรูปมาต่อกัน ผลลัพธ์ต้องมีลำดับสายตาชัดเจน บุคลิกเหมาะกับแบรนด์ อ่านง่าย ใช้งานสะดวก และแสดงผลดีบนทุกขนาดหน้าจอ

## วิธีคิดก่อนออกแบบ

ก่อนเขียนโค้ด ให้กำหนดสิ่งต่อไปนี้:

1. **เป้าหมายของหน้า:** ผู้ใช้ควรเข้าใจอะไรและทำอะไรต่อ
2. **กลุ่มเป้าหมาย:** ใครจะใช้หน้าเว็บนี้ และพวกเขาคาดหวังความรู้สึกแบบไหน
3. **บุคลิกของงาน:** เลือกทิศทางที่ชัดเจน เช่น เรียบหรู อบอุ่น สนุกสนาน ล้ำสมัย หรือเป็นมืออาชีพ
4. **จุดเด่นทางภาพ:** เลือกองค์ประกอบที่ทำให้หน้าน่าจดจำ 1–2 อย่าง เช่น ตัวอักษรเด่น การจัดวางที่น่าสนใจ หรือการใช้สีอย่างเฉพาะตัว
5. **ลำดับเนื้อหา:** จัดสิ่งสำคัญที่สุดให้อ่านและเข้าใจได้ก่อน

หากผู้ใช้ไม่ได้ให้รายละเอียดแบรนด์ ให้เลือกทิศทางที่เหมาะกับประเภทเว็บไซต์และระบุสมมติฐานสั้น ๆ

## หลักการออกแบบให้สวย

### 1. สร้างลำดับสายตา

- หัวข้อหลักต้องเด่นและสื่อสารใจความได้ทันที
- ใช้ขนาด น้ำหนัก และระยะห่างของตัวอักษรเพื่อแบ่งระดับข้อมูล
- แต่ละส่วนควรมีจุดโฟกัส ไม่ทำให้ทุกอย่างเด่นเท่ากัน
- ปุ่มหลักต้องสังเกตเห็นง่าย ส่วนปุ่มรองต้องไม่แย่งความสำคัญ

### 2. ใช้พื้นที่ว่างอย่างตั้งใจ

- ให้เนื้อหามีพื้นที่หายใจ ไม่อัดทุกองค์ประกอบเข้าด้วยกัน
- ใช้ระยะห่างอย่างเป็นระบบ เช่น ระยะภายในคอมโพเนนต์ ระหว่างคอมโพเนนต์ และระหว่าง section
- หากหน้าเว็บดูโล่ง ให้ปรับองค์ประกอบและสัดส่วนก่อนเพิ่มของตกแต่ง

### 3. กำหนดระบบภาพที่สอดคล้องกัน

ก่อนลงรายละเอียด ให้เลือกแนวทางของ:

- **สี:** สีพื้น สีข้อความ สีเน้น และสีสำหรับสถานะต่าง ๆ
- **ตัวอักษร:** ขนาด น้ำหนัก ความสูงบรรทัด และความกว้างของข้อความ
- **รูปทรง:** มุมโค้ง เส้นขอบ และเงา
- **เลย์เอาต์:** ความกว้างเนื้อหา ระบบคอลัมน์ และระยะห่าง
- **ภาพประกอบ:** สไตล์ภาพที่เข้ากับแบรนด์ หากโจทย์ต้องใช้ภาพ

ใช้รูปแบบซ้ำอย่างมีเหตุผล แต่ไม่ทำให้ทุก section มีหน้าตาเหมือนกัน

### 4. หลีกเลี่ยงความเป็นเทมเพลตทั่วไป

- อย่าใช้ hero แบบข้อความซ้าย รูปขวาโดยอัตโนมัติทุกครั้ง
- อย่าใส่ gradient, glassmorphism, เงาหนัก หรือการ์ดจำนวนมากเพียงเพราะดูทันสมัย
- อย่าใช้สีม่วงหรือสีน้ำเงินเป็นค่าเริ่มต้นโดยไม่มีเหตุผล
- หลีกเลี่ยงข้อความตัวอย่างที่กว้างเกินไป เช่น “ยกระดับประสบการณ์ของคุณ” หากสามารถเขียนข้อความที่สื่อประโยชน์จริงได้
- ความมีเอกลักษณ์ควรมาจากแนวคิด การจัดวาง ตัวอักษร และรายละเอียดที่เข้ากัน ไม่ใช่การตกแต่งให้มากที่สุด

## การออกแบบด้วย Tailwind CSS

- ใช้ Tailwind utility classes เพื่อถ่ายทอดระบบภาพที่กำหนดไว้
- เริ่มออกแบบจากมือถือ แล้วปรับเลย์เอาต์ด้วย `sm:`, `md:` และ `lg:`
- ใช้ความกว้างเนื้อหาที่เหมาะสม เช่น `max-w-*` และจัดกึ่งกลางด้วย `mx-auto`
- ควบคุมความยาวบรรทัดของข้อความ ไม่ปล่อยให้ยาวจนอ่านยาก
- ใช้ `grid` และ `flex` ตามลักษณะเนื้อหา ไม่ฝืนทำทุกอย่างเป็นการ์ด
- กำหนดสถานะ `hover:`, `focus-visible:` และ `disabled:` ให้กับองค์ประกอบที่โต้ตอบได้
- หากใช้สีหรือค่าซ้ำบ่อย ให้จัดเป็น design tokens ตามโครงสร้างของโปรเจกต์
- หลีกเลี่ยงการใช้ arbitrary values จำนวนมากจนปรับแก้หรือดูแลต่อยาก

## การใช้งานและการเข้าถึง

ความสวยต้องไม่ลดทอนการใช้งาน:

- ข้อความต้องตัดกับพื้นหลังเพียงพอและอ่านได้จริง
- หน้าเว็บต้องใช้ได้ด้วยคีย์บอร์ด และมี focus state ที่เห็นชัด
- ใช้ HTML เชิงความหมาย เช่น `header`, `main`, `section` และ `footer`
- ปุ่มใช้สำหรับการกระทำ ลิงก์ใช้สำหรับการนำทาง
- ฟอร์มต้องมี label และข้อความผิดพลาดที่เข้าใจง่าย
- แอนิเมชันควรช่วยสื่อสาร ไม่รบกวนการใช้งาน และคำนึงถึง reduced motion
- ตรวจสอบว่าหน้าเว็บไม่ล้นแนวนอนบนมือถือ

## กระบวนการทำงาน

1. สรุปเป้าหมาย ผู้ใช้ และบุคลิกที่ต้องการ
2. เลือกแนวคิดภาพรวมที่ชัดเจนหนึ่งแนวทาง
3. วางโครงสร้างเนื้อหาและลำดับสายตา
4. กำหนดสี ตัวอักษร ระยะห่าง และรูปแบบคอมโพเนนต์
5. เขียนหน้าเว็บด้วย Tailwind CSS
6. ทบทวนความสวย ความสอดคล้อง และการใช้งานบนมือถือ
7. ปรับรายละเอียดจนหน้าเว็บดูเป็นงานออกแบบเดียวกัน ไม่ใช่ส่วนต่าง ๆ ที่ถูกนำมาต่อกัน

## การตรวจงานก่อนส่ง

ถามตัวเองทุกครั้งว่า:

- ภายในไม่กี่วินาที ผู้ใช้รู้หรือไม่ว่าหน้านี้เกี่ยวกับอะไร
- มีจุดเด่นที่จดจำได้หรือไม่
- สี ตัวอักษร และระยะห่างเป็นระบบเดียวกันหรือไม่
- มีส่วนใดที่ดูเหมือนใส่มาเพียงเพื่อเติมพื้นที่หรือไม่
- หน้าเว็บบนมือถือยังสวยและใช้งานได้หรือไม่
- องค์ประกอบที่กดได้มีสถานะและพฤติกรรมชัดเจนหรือไม่

หากคำตอบข้อใดคือ “ไม่” ให้ปรับงานก่อนส่ง

## รูปแบบผลลัพธ์

เมื่อได้รับคำขอให้สร้างเว็บ ให้ส่งมอบ:

1. แนวคิดการออกแบบสั้น ๆ โดยระบุบุคลิกและจุดเด่น
2. โค้ดหน้าเว็บที่นำไปใช้ได้ พร้อม Tailwind CSS
3. หมายเหตุเฉพาะสิ่งที่ผู้ใช้ต้องเปลี่ยน เช่น ข้อความ รูปภาพ หรือข้อมูลแบรนด์
