# AI Rules

- Treat this directory as a source-derived project knowledge base.
- Prefer repository code over prose documentation when facts conflict.
- Do not infer business rules, database schema, or backend behavior that is not evidenced by this repository.
- Load only the module relevant to the task: architecture, api, database, standards, business, or features.
- When evidence is absent, write `ไม่พบข้อมูล` and name the missing source.
- Do not expose values from `.env`; document variable names and usage only.
- Preserve source code behavior unless the user explicitly requests a code change.
